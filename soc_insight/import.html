SOC Insight analyses alerts that other tools produce (SIEM, EDR, firewall, log exports). It does not sniff networks. Imported alerts get an RA- code and are tagged with their source; repeat imports skip duplicates. Imported alerts start as Open with no acknowledgement time (real times are unknown, so none are invented).

1. Upload a CSV / JSON export

Max 2 MB / 5000 rows. Column names are matched flexibly: title (or name, alert, rule_name, message), severity (critical/high/medium/low, info, warning, or 0–10), timestamp (ISO 8601 or epoch; stored as UTC), source_ip, destination_ip, category, description, id. Only title is required. Try sample_real_alerts.csv.

2. Webhook (push from a SIEM or script)

POST JSON to /api/ingest with your API key. Keep the key private.

Invoke-RestMethod -Uri http://127.0.0.1:5000/api/ingest -Method Post -Headers @{"X-API-Key"="{{ key }}"} -ContentType "application/json" -Body '{"title":"Failed SSH logins","severity":"high","source_ip":"203.0.113.9","timestamp":"2026-10-10T09:30:00Z"}'

3. Windows failed-logon collector (this PC)

Reads Security event 4625 from the last 24 hours on this computer only and raises an alert for any source IP with 5+ failures (Medium; High at 20+). Needs a terminal started with Run as administrator. Windows only. Not tested on Windows by the author.
